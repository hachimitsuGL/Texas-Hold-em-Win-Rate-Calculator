# Texas Hold'em Win Rate Calculator

プレイヤーのテキサスホールデムにおけるハンドの勝率をリアルタイムで計算できるアプリ。

## 実装済みの機能

- プレイヤーのホールカードとコミュニティカードを設定
- ポーカーハンド（役）の判定
- 2人のプレイヤーのハンドの強さ（ホールカード＋コミュニティカード）を比較
- 勝者の勝率を100%として表示
